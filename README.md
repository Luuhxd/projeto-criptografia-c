# 🔐 Criptografia com Cifra de César e P.A.
 
Projeto em **linguagem C** que criptografa uma palavra em duas etapas, unindo **programação**, **matemática (Progressão Aritmética)** e **criptografia simples**.
 
---
 
## 📖 Sobre o projeto
 
O programa pede uma palavra ao usuário e a embaralha seguindo duas regras:
 
1. **Cifra de César:** cada letra é trocada por outra que está **4 posições à frente** no alfabeto.
   Exemplo: `A → E`, `B → F`, `X → B` (depois do Z, volta para o A).
2. **Cifra com P.A.:** cada letra anda um pouco mais que a anterior. O deslocamento aumenta de **3 em 3**: 3, 6, 9, 12...
Usar as duas juntas deixa a mensagem mais difícil de decifrar.
